Path 拼接与 SQLite 连接

1. 这段代码用来做什么
聊天项目要保存会话和消息。Python 要先找到数据库文件、建立连接，之后才能对数据库执行 INSERT、SELECT 等 SQL。
这次用 path_practice.db 练习定位和连接；项目实际使用的数据库文件是 data/chat.db。

2. 最小示例
from pathlib import Path
import sqlite3

root = Path("F:/学习/项目/fastapi_ai_service")
db_path = root / "data" / "path_practice.db"
print(db_path)

conn = sqlite3.connect(db_path)
conn.close()

打印出的目标路径：F:\学习\项目\fastapi_ai_service\data\path_practice.db

3. 每个名字的作用
root：项目根目录的地址。
db_path：数据库文件的地址；它是 Path 对象，不是数据库连接。
sqlite3：Python 自带的操作 SQLite 数据库的模块，先用 import sqlite3 导入。
sqlite3.connect(db_path)：根据这个地址打开数据库，返回连接对象。
conn：保存返回的连接对象，以后可通过它执行 SQL。
conn.close()：用完关闭连接，不会删除数据库文件。

4. 容易混淆的地方
Path 里的 / 用来拼接目录和文件名，不是做数学除法。
变量名必须保持一致：定义 db_path 后，连接时也写 db_path；写成 dp_path 会报 NameError。
如果 data 文件夹已存在、数据库文件还不存在，connect 通常会创建这个 .db 文件；只连接不会自动创建 conversations/messages 表。
在聊天中把代码写对，与实际运行并检查数据库文件是两件事；本例目前只完成了纸面练习。
